# ชุดทดสอบอัตโนมัติของ Sellora

[English](README.md) | **ภาษาไทย**

ชุดทดสอบนี้เปิดแอปใน Chrome แบบไม่มีหน้าจอ (headless) แล้วกดใช้งานเหมือนผู้ใช้จริง
เช่น สมัครบัญชี สร้างออเดอร์ ใช้คูปอง บันทึกรายจ่าย และสลับไปจอมือถือ จากนั้นตรวจว่าผลลัพธ์ถูกต้อง

## ติดตั้ง (ทำครั้งเดียว)

ต้องมี Python 3.8 ขึ้นไป แล้วพิมพ์คำสั่งนี้ใน Terminal หรือ Command Prompt

```
pip install playwright pillow
python -m playwright install chromium
```

## รันทั้งหมด

เข้าไปที่โฟลเดอร์ `tests` แล้วพิมพ์

```
python run_all.py
```

ใช้เวลาประมาณ 6–8 นาที จากนั้นจะสรุปผลว่าผ่านกี่ชุดจาก 19 ชุด

ถ้าอยากรันแค่บางช่วง ใส่เลขชุดแรกและชุดสุดท้ายต่อท้าย เช่น `python run_all.py 12 19`

## รันทีละชุด

ชุดที่ชื่อขึ้นต้นด้วย `01` และชุดตรวจบัค (`03`, `05`, `07`, `08`, `10`) ต้องใส่ที่อยู่ของแอปต่อท้าย เช่น

```
python 01_end_to_end.py ../Sellora_Seller_Center.html
python 05_review2_bugs_19-38.py ../Sellora_Seller_Center.html
```

ชุดอื่นรันได้เลย เช่น `python 16_income_and_expenses.py`

## แต่ละชุดตรวจอะไร

| ไฟล์ | ตรวจอะไร |
|---|---|
| `01_end_to_end.py` | ทุกหน้าและทุกฟอร์มหลัก (รันอีกรอบในโหมดจำลองเบราว์เซอร์เก่าด้วย `force_gap.js`) |
| `02_browser_environments.py` | private mode, ไม่มี Web Crypto, เบราว์เซอร์ในแอป LINE, ปิด JavaScript, backup/restore |
| `03`, `05`, `07`, `08`, `10` | ทำตามขั้นตอนในรายงานบัคแต่ละรอบ ต้องได้ "bugs still present: 0" |
| `04`, `06`, `09` | พฤติกรรมใหม่ เช่น แก้ไขออเดอร์ ปุ่ม Back และ focus ในกล่อง |
| `11_part_payments.py` | จ่ายบางส่วน จ่ายส่วนที่เหลือ และคืนเงิน |
| `12_refunds_and_hints.py` | ยอดคืนเงินและข้อความใต้ช่องส่วนลด |
| `13_login_and_preview_windows.py` | ล็อกอินในหน้าต่างพรีวิว ปุ่มร้านตัวอย่าง และหน้าล็อกอินบนจอขนาดต่างๆ |
| `14_sample_data_audit.py` | ข้อมูลตัวอย่างสัมพันธ์กัน เช่น สต็อก ยอดขายสินค้า คูปอง และค่าส่ง |
| `15_month_view.py` | โหมด Month และการเลือกเดือน |
| `16_income_and_expenses.py` | รายได้ รายจ่าย กำไรสุทธิ และการบันทึกรายจ่าย |
| `17_year_view.py` | โหมด Year กราฟ 12 เดือน และสรุปทั้งปี |
| `18_review6_no_future_data.py` | ไม่มีข้อมูลล่วงหน้า และจุดเล็กๆ จากรีวิวรอบที่ 6 |

ไฟล์ `preview_frame.html` เป็นกรอบจำลองหน้าต่างพรีวิวที่บล็อกการส่งฟอร์ม ส่วนรูปภาพที่ชุดทดสอบถ่ายไว้จะอยู่ในโฟลเดอร์ `shots`
