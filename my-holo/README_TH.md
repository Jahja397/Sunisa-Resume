# MYHOLO ✦ Y2K Space

[Read in English](README_EN.md)

MYHOLO คือเว็บแชทโซเชียลหน้าตาสไตล์ Y2K ทั้งสีพาสเทลไล่ระดับ ฟอนต์พิกเซล และประกายวิบวับลอยอยู่ด้านหลัง สร้างหน้าโปรไฟล์ของตัวเอง เข้าไปแชทในห้องสด เพิ่มเพื่อน แล้วคุยกันแบบส่วนตัวได้ ทุกอย่างอัปเดตแบบเรียลไทม์ ข้อความใหม่ คำขอเป็นเพื่อน และสถานะออนไลน์จะขึ้นทันทีโดยไม่ต้องรีเฟรช

เอกสารนี้อธิบายทุกอย่างที่ทำได้ใน MYHOLO ไล่ทีละหน้า

---

## หน้าหลักๆ ของเว็บ

หลังล็อกอิน เมนูด้านบนจะพาไปได้ 5 ที่:

| เมนู | มีอะไรบ้าง |
| --- | --- |
| **Home** | การ์ดทักทาย จำนวนคนที่ออนไลน์อยู่ ปุ่มเปิดการแจ้งเตือน และทางลัดไปหน้าอื่นๆ |
| **Chat** | รายชื่อห้องแชทสาธารณะทั้ง 9 ห้อง |
| **People** | ค้นหาคนด้วยชื่อผู้ใช้หรือ ID |
| **My Page** | หน้าโปรไฟล์ของเรา รายชื่อเพื่อน และคนที่เราบล็อก |
| **Inbox** | คำขอเป็นเพื่อน และแชทส่วนตัวทั้งหมด |

ป้ายสีแดงบนเมนู **Inbox** จะนับจำนวนแชทที่ยังไม่อ่านรวมกับคำขอเป็นเพื่อนใหม่ และชื่อแท็บของเบราว์เซอร์ก็จะขึ้นตัวเลขเดียวกัน เช่น *(2) MYHOLO*

## 1. สมัครสมาชิก

- **สมัคร** ด้วยชื่อผู้ใช้ อีเมล และรหัสผ่าน รหัสผ่านต้องยาวอย่างน้อย 6 ตัว
- **กติกาชื่อผู้ใช้**: ยาว 3–20 ตัว ใช้ตัวอักษรอังกฤษ ตัวเลข `_` หรือภาษาไทยได้ แต่ห้ามขึ้นต้นด้วยสระบน สระล่าง หรือวรรณยุกต์ (เช่น ั หรือ ่) และชื่อต้องไม่ซ้ำกับใคร
- **ยืนยันอีเมล**: สมัครเสร็จ MYHOLO จะส่งลิงก์ไปที่อีเมล ต้องกดลิงก์ก่อนถึงจะใช้เว็บได้ หน้า *Check your email* จะรู้เองภายในไม่กี่วินาทีหลังกดลิงก์ หรือจะกดปุ่ม **I've verified ✓** เองก็ได้
- **อีเมลไม่มา?** เช็คในจดหมายขยะ (Spam) หรือแท็บโปรโมชัน หรือกด **Send the link again** (ส่งใหม่ได้นาทีละครั้ง) ถ้าพิมพ์อีเมลผิด กด **Wrong email? Start over** เพื่อยกเลิกบัญชีนั้นแล้วสมัครใหม่
- **ชื่อผู้ใช้จะถูกจองหลังยืนยันอีเมลแล้ว** ถ้าระหว่างนั้นมีคนอื่นเอาชื่อนั้นไปใช้ก่อน MYHOLO จะให้เลือกชื่อใหม่
- **ID ประจำตัว**: ทุกบัญชีได้ ID แบบสุ่ม เป็นตัวอักษร 2 ตัวกับตัวเลข 4 หลัก เช่น `#KX2048` ไม่มีตัว I กับ O เลย จะได้ไม่สับสนกับเลข 1 และ 0

## 2. ล็อกอินและออกจากระบบ

- **ล็อกอินด้วยอีเมลกับรหัสผ่าน** ใช้ชื่อผู้ใช้ล็อกอินไม่ได้ เพื่อเก็บอีเมลของทุกคนไว้เป็นความลับ
- **ลืมรหัส?** พิมพ์อีเมลในหน้าล็อกอินแล้วกด **Forgot password?** ระบบจะส่งลิงก์ตั้งรหัสใหม่ไปที่อีเมลนั้น
- **บัญชีเก่าที่ยังไม่เคยยืนยันอีเมล** จะเจอหน้า *Verify your email* ก่อน มีปุ่มให้กดส่งลิงก์ยืนยัน
- **ถ้าหน้าโปรไฟล์หายไป** (เช่นโดนลบโดยไม่ตั้งใจ) ตัวบัญชียังใช้ได้อยู่ ตอนล็อกอินจะเจอหน้า *Restore your page* ที่ใส่ชื่อเดิมไว้ให้แล้ว กดปุ่มเดียวหน้าก็กลับมา จะได้ ID ใหม่ สีกลับเป็นค่าเริ่มต้น ข้อความเก่ายังอยู่ครบ แต่ต้องแอดเพื่อนกันใหม่
- **ออกจากระบบ** ด้วยปุ่ม **[Logout]** ในเมนู ถ้าออกจากระบบในแท็บหนึ่ง แท็บอื่นในเบราว์เซอร์เดียวกันก็จะออกด้วย

## 3. หน้า Home

- การ์ดทักทาย มีรูปโปรไฟล์ ชื่อผู้ใช้ ID และสถานะออนไลน์ของเรา พร้อมปุ่มไปหน้า My Page
- **เปิดการแจ้งเตือน**: กดปุ่มครั้งเดียว เบราว์เซอร์จะขออนุญาต MYHOLO ไม่ขอเองโดยที่เราไม่ได้กด
- **Live & Real-time** บอกว่าตอนนี้มีคนออนไลน์อยู่กี่คน
- ข้อความเตือนว่าแต่ละแชทโชว์ 80 ข้อความล่าสุด
- ทางลัดไปหน้า World Chat, Inbox และ Find People

## 4. ห้องแชท

มีห้องสาธารณะทั้งหมด 9 ห้อง ทุกคนที่ยืนยันอีเมลแล้วเข้าได้:

| ห้อง | ธีม |
| --- | --- |
| #GlobalChat | ห้องรวมหลัก |
| #Y2K_Nostalgia | ย้อนวัยยุค Y2K |
| #GamingHub | สายเกม |
| #MusicLounge | สายดนตรี |
| #ArtGallery | สายศิลปะ |
| #MeetFriends | หาเพื่อนใหม่ |
| #DatingRoom | หาคู่ |
| #LGBTQ+ | Pride |
| #HelpCenter | ถามปัญหา ขอความช่วยเหลือ |

ในห้องแชททำอะไรได้บ้าง:

- **อ่านข้อความแบบสด** ทุกข้อความบอกชื่อคนส่ง ID และเวลา ถ้ามี ♡ ต่อท้ายชื่อ แปลว่าคนนั้นเป็นเพื่อนเรา
- **ส่งข้อความ** ด้วยปุ่ม **Enter** หรือปุ่ม **Send** ข้อความหนึ่งยาวได้สูงสุด 1,000 ตัวอักษร
- **ใส่อีโมจิ** ด้วยปุ่ม 😀 จะเปิดแผงอีโมจิ 116 แบบ อีโมจิจะไปอยู่ตรงตำแหน่งเคอร์เซอร์ แผงจะปิดเองตอนกดส่ง แตะที่อื่น หรือกด Esc บนมือถือเลือกอีโมจิแล้วคีย์บอร์ดจะไม่เด้งขึ้นมาทุกครั้ง
- **ส่งรูป** ด้วยปุ่ม 🖼️ ส่งรูปได้ขนาดไม่เกิน 10 MB MYHOLO จะย่อรูปให้เหลือไม่เกิน 900 พิกเซลและบีบอัดก่อนส่ง ส่วนที่เป็นพื้นใสจะกลายเป็นสีขาว ไม่ใช่สีดำ
- **ลบข้อความของตัวเอง** ด้วยปุ่ม 🗑 บนคอมจะโผล่ตอนเอาเมาส์ไปชี้ข้อความ บนมือถือจะโชว์จางๆ ตลอด กดแล้วจะมีให้ยืนยันก่อนลบ
- **รู้ว่าข้อความเป็นของวันไหน** มีป้ายคั่นอย่าง *Today*, *Yesterday* หรือวันที่
- **เลื่อนอ่านย้อนหลังได้สบาย** แชทจะเลื่อนลงไปหาข้อความใหม่ให้เฉพาะตอนที่เราอยู่ล่างสุดอยู่แล้ว เวลาอ่านข้อความเก่าจะไม่โดนดึงกลับลงไป
- **คลิกชื่อใครก็ได้** เพื่อเปิดดูโปรไฟล์ของคนนั้น
- ข้อความของคนที่เราบล็อกจะถูกซ่อนไว้

## 5. ค้นหาคน

ในหน้า **People** ค้นหาได้ 2 แบบ:

- **ด้วยตัวอักษรต้นชื่อ** ทั้งภาษาอังกฤษและภาษาไทย เช่นพิมพ์ `be` จะเจอ `beam`
- **ด้วย ID แบบเต็ม** จะพิมพ์ `#` หรือไม่พิมพ์ก็ได้ เช่น `#KX2048` หรือ `KX2048`

ผลการค้นหาแต่ละคนจะโชว์รูปโปรไฟล์ ID และสถานะออนไลน์ พร้อมปุ่มที่เปลี่ยนไปตามความสัมพันธ์:

| ปุ่ม | ความหมาย |
| --- | --- |
| **+ Add Friend** | ส่งคำขอเป็นเพื่อน |
| **Requested ✓** | เราส่งคำขอไปแล้ว |
| **Accept ♡** | เขาส่งคำขอมาหาเรา กดเพื่อรับ |
| **Chat ♡** | เป็นเพื่อนกันแล้ว กดเพื่อเปิดแชทส่วนตัว |
| **Blocked** | เราบล็อกคนนี้อยู่ |
| **You ✦** | คนนี้คือเราเอง |

คลิกที่ผลการค้นหาเพื่อเปิดดูโปรไฟล์เต็ม และถ้ากด Back กลับมา ผลการค้นหาเดิมก็ยังอยู่

## 6. หน้าโปรไฟล์ของคนอื่น

หน้าโปรไฟล์จะโชว์รูปโปรไฟล์ ชื่อผู้ใช้ ID จำนวนเพื่อน สถานะออนไลน์ (หรือเห็นล่าสุดเมื่อไหร่) caption และ bio ปุ่มจะเปลี่ยนไปตามความสัมพันธ์:

- **ยังไม่ได้เป็นเพื่อน**: ปุ่ม **+ Add Friend** และ **Block**
- **เราส่งคำขอไปแล้ว**: ขึ้นว่า *Request sent ✓* พร้อมปุ่ม **Cancel request** เพื่อยกเลิก
- **เขาส่งคำขอมาหาเรา**: ปุ่ม **Accept ♡** หรือ **Decline**
- **เป็นเพื่อนกันแล้ว**: ปุ่ม **Chat ♡** และ **Unfriend**
- **เราบล็อกอยู่**: ปุ่ม **Unblock**

## 7. ระบบเพื่อน

- **คลิกชื่อแล้วไม่กลายเป็นเพื่อนโดยไม่ตั้งใจแน่นอน** จะเป็นเพื่อนกันได้ต่อเมื่อเราส่งคำขอและอีกฝ่ายกดรับเท่านั้น
- **ตอนมีคนส่งคำขอมา** จะมีป๊อปอัปเด้งขึ้นพร้อมปุ่ม **View** และตัวเลขบน Inbox จะเพิ่มขึ้นหนึ่ง
- **ถ้าเขาส่งคำขอมาหาเราก่อนแล้ว** หน้าโปรไฟล์และผลการค้นหาของเขาจะขึ้นปุ่ม **Accept ♡** แทน **+ Add Friend** คำขอเลยไม่ซ้อนกันสองอัน
- **ตอนอีกฝ่ายกดรับคำขอของเรา** จะมีป๊อปอัปบอก แล้วคนนั้นจะขึ้นใน Inbox และใน My Page
- **Unfriend** จะยกเลิกการเป็นเพื่อนทั้งสองฝั่ง
- **Block** จะยกเลิกการเป็นเพื่อน ยกเลิกคำขอที่ค้างอยู่ ทำให้คนนั้นส่งคำขอหรือส่งข้อความส่วนตัวหาเราไม่ได้ และซ่อนข้อความของเขาในห้องแชทไม่ให้เราเห็น ปลดบล็อกได้จากหน้าโปรไฟล์ของเขา หรือจากหน้า My Page

## 8. แชทส่วนตัว

- แชทส่วนตัว **คุยได้เฉพาะกับเพื่อน** และมีแค่เราสองคนที่อ่านได้
- ใช้ได้ทุกอย่างเหมือนห้องแชท ทั้งอีโมจิ ส่งรูป ลบข้อความของตัวเอง และป้ายคั่นวัน
- แถบด้านบนโชว์ชื่อเพื่อน (คลิกเพื่อดูโปรไฟล์) และบอกว่าเพื่อนออนไลน์อยู่ไหม
- **เปิดแชทแล้วนับว่าอ่านแล้วทุกเครื่อง** จุดแจ้งเตือนจะหายทั้งในมือถือและในคอม
- ถ้าเพื่อนกด Unfriend ระหว่างที่เราเปิดแชทอยู่ ช่องพิมพ์จะเปลี่ยนเป็นข้อความบอกว่าไม่ได้เป็นเพื่อนกันแล้ว
- ถ้าเป็นเพื่อนกันแค่ฝั่งเดียว (ค้างมาจาก MYHOLO เวอร์ชันเก่า) ในแชทจะบอกว่าอีกฝ่ายยังไม่ได้แอดเรากลับ พร้อมปุ่ม **Send request** ให้ส่งคำขอ

## 9. Inbox

- **คำขอเป็นเพื่อน** อยู่ด้านบนสุด แต่ละอันมีปุ่ม **Accept ♡** และ **Decline**
- **แชทของเรา** อยู่ด้านล่าง แชทที่คุยล่าสุดขึ้นก่อน แต่ละแถวโชว์รูปโปรไฟล์กับจุดสถานะออนไลน์ของเพื่อน ชื่อ ตัวอย่างข้อความล่าสุด (ขึ้นว่า *You:* ถ้าเราเป็นคนส่ง และ 📷 *Image* ถ้าเป็นรูป) และเวลาหรือวันที่
- **แชทที่ยังไม่อ่าน** จะมีจุดสีชมพูและชื่อเป็นตัวหนา

## 10. การแจ้งเตือน

- **ป๊อปอัปในเว็บ** เด้งขึ้นตอนเพื่อนทักมา (มีปุ่ม **Open**) ตอนมีคนส่งคำขอเป็นเพื่อน (มีปุ่ม **View**) และตอนมีคนกดรับคำขอของเรา
- **การแจ้งเตือนของเบราว์เซอร์** ถ้าเปิดไว้ จะเด้งตอนที่เราไม่ได้ดูแท็บ MYHOLO อยู่ กดที่แจ้งเตือนแล้วจะเปิดแชทนั้นให้เลย
- **บนมือถือ** ป๊อปอัปจะขึ้นด้านบนของจอ จะได้ไม่บังช่องพิมพ์ข้อความ

## 11. หน้า My Page และการแก้โปรไฟล์

- **My Page** โชว์รูปโปรไฟล์ ชื่อผู้ใช้ ID caption และ bio ของเรา รูปโปรไฟล์ใช้ตัวอักษรแรกของชื่อ ถ้าเป็นชื่อภาษาไทยจะข้ามสระบน สระล่าง และวรรณยุกต์ ตัวอักษรเลยดูถูกต้อง
- **Friends** โชว์เพื่อนทั้งหมดเป็นตาราง คลิกที่เพื่อนเพื่อเปิดแชทกับคนนั้น
- **Blocked** โชว์คนที่เราบล็อก แต่ละคนมีปุ่ม **Unblock** ส่วนนี้จะขึ้นเฉพาะตอนที่เราบล็อกใครอยู่
- **Edit Profile** แก้ได้ดังนี้:
  - เลือก **สี 2 สี** สำหรับไล่ระดับในรูปโปรไฟล์
  - เขียน **caption** ได้ไม่เกิน 100 ตัวอักษร
  - เขียน **bio** ได้ไม่เกิน 500 ตัวอักษร ขึ้นบรรทัดใหม่ได้

## 12. สถานะออนไลน์

- **จุดสีเขียว** แปลว่าคนนั้นเปิด MYHOLO อยู่ในอย่างน้อยหนึ่งเครื่องหรือหนึ่งแท็บ
- **จุดสีเทา** แปลว่าออฟไลน์ พร้อมบอก *last seen* เป็นเวลา (ถ้าเป็นวันนี้) หรือเป็นวันที่
- เปิดหลายแท็บหรือหลายเครื่องพร้อมกันก็ไม่เพี้ยน จะขึ้นออฟไลน์ก็ต่อเมื่อปิดหรือออกจากระบบอันสุดท้ายแล้ว

## 13. ลิงก์ การรีเฟรช และปุ่ม Back

- **ทุกหน้ามีลิงก์ของตัวเอง** เช่น `#/room/global` สำหรับห้องแชท `#/inbox` สำหรับ Inbox หรือ `#/u/...` สำหรับโปรไฟล์ของแต่ละคน
- **รีเฟรชแล้วยังอยู่หน้าเดิม** และปุ่ม Back กับ Forward ของเบราว์เซอร์ใช้ย้อนไปมาระหว่างหน้าใน MYHOLO ได้
- **ถ้าเปิดลิงก์ตอนยังไม่ได้ล็อกอิน** พอล็อกอินเสร็จจะพาไปหน้านั้นให้เลย

## 14. มือถือและภาษาไทย

- หน้าเว็บปรับให้พอดีกับจอมือถือ เทสถึงจอกว้าง 320 พิกเซล ไม่มีอะไรล้นหรือโดนตัด
- ใช้ภาษาไทยได้ทุกที่ ทั้งชื่อผู้ใช้ ข้อความ caption และ bio ตัวอักษรไทยใช้ฟอนต์ Chakra Petch ให้เข้ากับสไตล์พิกเซล

## 15. ความปลอดภัยและความเป็นส่วนตัว

- **ต้องใช้อีเมลจริง** บัญชีที่ใช้อีเมลมั่วจะยืนยันไม่ได้ เลยอ่านหรือโพสต์อะไรไม่ได้เลย
- **อีเมลของเราไม่โชว์** ให้คนอื่นเห็น
- **ไม่มีใครปลอมตัวเป็นเราได้** ทุกข้อความจะโชว์ชื่อผู้ใช้และ ID จริงของคนส่งเสมอ
- **แชทส่วนตัวเป็นความลับ** อ่านได้แค่เพื่อนสองคนในแชทนั้น
- **ไม่มีใครแก้โปรไฟล์ของเราได้** นอกจากตัวเราเอง
- **เวลาของข้อความมาจาก server** ข้อความเลยเรียงถูกลำดับเสมอ แม้นาฬิกาในเครื่องของใครจะเพี้ยน
- **การบล็อก** หยุดคำขอและข้อความที่เราไม่อยากได้
